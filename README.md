# Dark Matter Profile Differentiation in SPARC Galaxies
**Author:** Bhasker Vasudevan | **Date:** March 2026 | **Status:** Paper under review

---

## Overview
This project investigates the core-cusp problem using rotation curve data from 175 late-type galaxies in the [SPARC database](http://astroweb.cwru.edu/SPARC/). Both NFW (cuspy) and pseudo-isothermal (cored) profiles are fitted to each galaxy's dark matter velocity component to identify what physically distinguishes core from cusp galaxies.

## Key Findings
- ISO profile preferred in 52% of galaxies; NFW in only 8.6%
- **Inner V_DM slope** (p = 0.003) and **ISO core radius r_c** (p = 0.028) are the only statistically significant differentiators between groups
- Among ISO galaxies, baryonic fraction correlates strongly with core radius — consistent with the baryonic feedback hypothesis
